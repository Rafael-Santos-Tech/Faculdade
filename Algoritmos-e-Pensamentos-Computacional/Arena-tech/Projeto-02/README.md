# 🚀 Missão Orbital | Avaliação de Desempenho de Cadetes

O **Missão Orbital** é um sistema acadêmico em **C**, desenvolvido colaborativamente em equipe. O algoritmo foi projetado para processar e classificar o desempenho de cadetes espaciais em treinamento, simulando regras estritas de avaliação.

O projeto foca na manipulação estruturada de dados de entrada de usuários, garantindo que o fluxo de decisão seja preciso e sem falhas lógicas.

### ⚙️ Funcionalidades e Regras de Negócio
- **Entrada e Processamento de Notas:** Recebe de forma dinâmica as pontuações individuais dos cadetes durante os ciclos de treinamento.
- **Cálculo de Performance:** Processa os valores inseridos aplicando fórmulas matemáticas para gerar a média exata de desempenho.
- **Classificação Automática:** Utiliza regras de condição (`if/else` e `switch`) para aprovar, reprovar e designar automaticamente o nível da missão ideal para o cadete de acordo com a sua nota final.

### 🛠️ Tecnologias Utilizadas
- **Linguagem:** `C`
- **Conceitos:** `Laços de Repetição (for/while/do-while)`, `Trabalho em Equipe`, `Versionamento`
- **Ferramentas:** `Git`, `GitHub`, `VS Code`
