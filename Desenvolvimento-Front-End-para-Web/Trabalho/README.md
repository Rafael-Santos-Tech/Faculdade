# 🍔 FoodLoop

O **FoodLoop** é uma aplicação web (Front-end) desenvolvida para simular um sistema de delivery e cardápio digital. O objetivo do projeto é oferecer uma experiência intuitiva e rápida para os usuários navegarem por categorias de alimentos, adicionarem itens ao carrinho e gerenciarem seus pedidos.

## 🚀 Funcionalidades

O projeto é composto por diversas telas que cobrem o fluxo completo de um aplicativo de delivery:

*   **Página Inicial & Menu:** Visualização dos destaques (`home.html`, `produtos.html`).
*   **Filtro por Categorias:** Busca de lanches, bebidas, doces, etc. (`categorias.html`).
*   **Carrinho e Pedidos:** Gerenciamento do que será comprado e histórico (`carrinho.html`, `pedidos.html`).
*   **Área do Cliente:** Criação de conta e login (`registro.html`, `login.html`).
*   **Favoritos:** Opção para salvar os pratos preferidos (`favoritos.html`).
*   **Institucional:** Páginas de contato e sobre o projeto (`contato.html`, `sobre.html`).

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as bases do desenvolvimento web:

*   **HTML5:** Estruturação semântica das páginas.
*   **CSS3:** Estilização, layout e responsividade (`style.css`).
*   **JavaScript (Vanilla):** Lógica de interatividade do lado do cliente (`app.js`).
