# 🎓 Repositório Acadêmico | Análise e Desenvolvimento de Sistemas

Bem-vindo ao meu repositório universitário! Aqui concentro os projetos, algoritmos e listas de exercícios práticos que desenvolvi ao longo do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

O objetivo deste espaço é documentar minha evolução técnica contínua, aplicando na prática os conceitos teóricos de arquitetura de software, estruturação de dados e regras de negócio.

---

## 🛠️ Tecnologias e Ferramentas Aplicadas

Os projetos e exercícios aqui armazenados foram construídos utilizando as seguintes tecnologias:

*   **Linguagens de Programação:** `C`, `Python`, `JavaScript`
*   **Fundamentos Web:** `HTML5`, `CSS3`
*   **Banco de Dados:** `MySQL`
*   **Ambientes e Ferramentas:** `VS Code`, `Git`

---

## 📂 Projetos em Destaque

Neste repositório, você encontrará a aplicação de lógica em cenários variados. Alguns dos principais escopos desenvolvidos incluem:

*   **Infinite Play (Python):** Sistema back-end desenvolvido focado no gerenciamento lógico de uma loja virtual de jogos. Este projeto foi construído em equipe durante a faculdade, com o objetivo de aplicar fundamentos de engenharia de software e versionamento colaborativo.
*   **Arena Tech (C):** Programa estruturado para o cálculo de custos, consumo de energia e dimensionamento de equipamentos de infraestrutura para grandes eventos de tecnologia.
*   **Missão Orbital (C):** Algoritmo de avaliação de desempenho estudantil. Processa notas de treinamento, calcula médias e automatiza a classificação de cadetes.
*   **Fundamentos de Algoritmos:** Pastas dedicadas à resolução de problemas lógicos focados em estruturas de condição, laços de repetição (for/while), vetores e matrizes.

## 🚀 Como Executar os Códigos

Caso deseje testar as aplicações localmente, siga as instruções de acordo com a linguagem do projeto:

### Para projetos em Python
Certifique-se de ter o [Python](https://www.python.org/downloads/) instalado na sua máquina. Abra o terminal na pasta do arquivo e execute:
```bash
python nome_do_arquivo.py 
```

### Para projetos em C
É necessário ter um compilador como o GCC (MinGW no Windows). Para compilar e rodar via terminal:
```bash
gcc nome_do_arquivo.c -o programa
./programa
```
